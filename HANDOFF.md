## Pitfall Log & Lessons Learned

| Date        | Category         | Issue / Trap Encountered                               | Root Cause & Solution                                                                                                                                                                                                                                                      |
| :---------- | :--------------- | :----------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _(Initial)_ | Setup            | Placeholder                                            | Document issues here as they are resolved.                                                                                                                                                                                                                                 |
| 2026-10-27  | Tooling          | Biome checks and enforces markdown formatting          | Biome CLI (`bun run check`) formats markdown files in addition to TypeScript/CSS. Running `bun run check:write` automatically aligns table pipes, list item indentation, and blank lines to prevent CI check failures.                                                     |
| 2026-10-27  | Architecture     | Symlink `CLAUDE.md -> AGENTS.md`                       | Claude Code / Anthropic agents expect `CLAUDE.md` while general agents expect `AGENTS.md`. Kept `CLAUDE.md` as a relative symlink to `AGENTS.md` to avoid diverging documentation.                                                                                         |
| 2026-10-27  | UI / SVG         | SVG `<defs>` gradient ID collisions in React           | When inlining SVG icons containing `<linearGradient id="...">` across multiple component instances, identical IDs clash. Use `React.useId()` to namespace def IDs dynamically.                                                                                             |
| 2026-10-27  | Testing / Motion | Missing `matchMedia` & `IntersectionObserver` in jsdom | When rendering Motion and `@animate-ui/react` components in Vitest / jsdom tests, missing `matchMedia`, `ResizeObserver`, and `IntersectionObserver` globals cause runtime exceptions. Mocked them in `src/test/setup.ts`.                                                 |
| 2026-10-27  | TypeScript       | `export *` collision on `animations` in icon barrel    | Each `@animate-ui/icons-*` component exports an `animations` object. Wildcard re-exporting in a barrel index causes TS2308 duplicate export errors. Explicitly re-export only the component and prop types.                                                                |
| 2026-10-27  | UI / Select      | Dropdown popup truncated & checkmark overlap           | `w-(--anchor-width)` and `alignItemWithTrigger=true` lock dropdown popup width to the trigger width (~180px), truncating long option descriptions. Use `min-w-[max(var(--anchor-width),320px)] w-max`, `align="start"`, and `alignItemWithTrigger=false`.                  |
| 2026-10-27  | UI / Icons       | Password toggle Eye squashing artifact                 | `@animate-ui/icons-lucide-eye` uses `scaleY` without SVG center origin, causing glitchy squashing on hover. Restored standard `Eye`/`EyeOff` from `lucide-react` for stable password inputs.                                                                               |
| 2026-10-27  | Architecture     | Cross-feature coupling in conversion hook              | `useConverter` in `convert-stickers` previously imported `fetchTelegramStickerSources` from `upload-stickers`. Extracted the conversion pipeline to `conversion-pipeline.ts` and abstracted input loading via `loadSources` in `App.tsx` to restore strict FSD boundaries. |
| 2026-10-27  | UI / Motion      | SlidingNumber frame thrashing during batch conversion  | Rapid 0-100% updates during frame encoding caused excessive spring DOM recalculations in `SlidingNumber`. Replaced with `tabular-nums font-mono` for crisp rendering and zero layout thrashing.                                                                            |
| 2026-10-27  | i18n             | Static locale evaluation in module scope               | Statically importing `t` at file level in `useConverter` caused messages to stay in Chinese when user switched to English. Used reactive `useI18n()` inside the hook to ensure runtime locale synchronization.                                                             |
| 2026-10-27  | UI / Typography  | Language toggle alignment & font-mono metric clash     | Using `font-mono` on CJK characters ('中') caused a 3.5px baseline offset relative to the SVG icon. Replaced with `font-medium text-xs leading-none` and unified `variant="outline"` (`h-7`) for visual consistency with sibling actions.                                  |
